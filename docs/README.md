# docs/

Specifications and structural documents governing the Research repository.

## Contents

- `research-repo-structure-spec_v1.0.md` — the repo's structure spec: directory
  tree, file formats (research questions, literature reviews, bibliographies,
  methods), naming conventions, cross-linking rules, migration plan.

## Conventions

- Specs are versioned (`<name>_spec_vN.M.md`, or `<name>-vN.M.md` for
  non-spec documents). Old versions stay under their own version — the
  audit trail is never rewritten; a new version supersedes with a changelog.
- Standing principle: specs are audited regularly against the governance
  principles. An audit that changes a spec produces a new version, never an
  edit of the old one.
