# Research — Historiotheque

The scholarly apparatus of the art-research practice: research questions, literature
reviews, bibliographies, and research methods. Counterpart to the main Historiotheque
repository, which remains the *release artifact* (the studio / sound lab / research lab
as cultural software).

## Contents

- `research-questions/` — one file per question (`RQ-YYYY-NNN`), each with a dated
  activity log; the README is the living index of clusters and statuses.
- `literature-reviews/` — one file per review, each ending in Works consulted + Open threads.
- `bibliographies/` — per-project bibliographies citing the master by ID.
- `BIBLIOGRAPHY.md` — the master annotated bibliography (`BIB-YYYY-NNN`, Chicago).
- `methods/` — one file per adopted method (`M-YYYY-NNN`); populated as the
  research-design reading progresses.
- `docs/` — specifications, including the repo structure spec.

## Conventions

IDs are never reused. Cross-links within the repo are relative; links to the main
Historiotheque repo (studio logs, releases, declarations) are absolute GitHub URLs.
