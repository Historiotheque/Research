# Master Bibliography (annotated)

Wide-scope, annotated bibliography of the practice. Each entry carries the author's
note on why the source matters — not just the citation.

- **IDs:** `BIB-YYYY-NNN`, never reused.
- **Standard:** Chicago author-date (per Studio Log Spec §8).
- **To add a citation:** tell Oracle "add a citation" and name the source (author,
  title, whatever else is remembered). Oracle formats it, assigns the next ID,
  appends it here, and reads it back for correction.
